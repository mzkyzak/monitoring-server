Panduan Setup Cloudflare Tunnel — Akses Laptop dari Mana Saja

Kenapa Cloudflare Tunnel?

Laptop di rumah (IP dinamis) bisa dapat domain publik tanpa Port Forwarding, tanpa IP Statis. Bot WA Anda di laptop bisa diakses dari HP atau luar kota 24/7!

1

Daftarkan Domain ke Cloudflare

Arahkan Nameserver domain ke Cloudflare (gratis). Masuk ke Cloudflare Dashboard → Zero Trust → Networks → Tunnels.

2

Install cloudflared di Laptop

# Windows (Powershell):
winget install Cloudflare.cloudflared

# Ubuntu Server:
sudo apt install cloudflared
3

Login & Buat Tunnel

cloudflared tunnel login
cloudflared tunnel create laptop-server
cloudflared tunnel run laptop-server
4

Arahkan Domain → Port Dashboard

Di Cloudflare Tunnel, tambahkan Public Hostname:

  • Subdomain: monitoring
  • Domain: domainanda.com
  • Type: HTTP | URL: localhost:4000

✅ Selesai! Dashboard Anda live di internet.
